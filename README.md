# Rafael Prestes

Site pessoal de apresentação, publicado com o GitHub Pages.

**Acesse:** https://rafajow19.github.io

## Sobre o projeto

Página de apresentação com formação, interesses e projetos de um estudante do curso Técnico em Informática no IFSP Campus Bauru. O visual usa tons de vermelho e uma aparência de terminal, combinando com os interesses em programação, cibersegurança e desenvolvimento de software.

A estrutura das seções foi inspirada no site do Prof. Rodrigo Campos, com conteúdo, cores e visual próprios.

## Tecnologias

- **HTML5**: estrutura e conteúdo da página
- **CSS3**: layout, cores, tema claro e escuro e responsividade (variáveis CSS, Grid e Flexbox)
- **JavaScript**: alternância de tema e filtro de projetos
- **GitHub Pages**: hospedagem gratuita do site

Não usa frameworks nem bibliotecas externas.

## Estrutura

```
├── index.html      # conteúdo da página
├── css/
│   └── style.css   # estilos
└── js/
    └── main.js     # tema e filtro de projetos
```

## Como rodar no seu computador

1. Baixe o projeto em **Code → Download ZIP**
2. Extraia o arquivo
3. Abra o `index.html` no navegador
